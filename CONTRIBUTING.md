# Contributing

Bug reports, docs fixes, and pull requests are welcome.

1. Open an [issue](https://github.com/ibigsnet/ThunderboltNet/issues) for discussion when the change is large.
2. Prefer focused PRs against `main`.
3. Test Thunderbolt apply / OpenFabric paths on real hardware when you change them.
4. Do not change Unraid’s main LAN (`br0`) behavior unless the user explicitly opts in.

Support: Unraid forum thread linked from the plugin’s Apps card.
