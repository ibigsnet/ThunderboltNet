**Thunderbolt Net**

Reliable **single-link** host-to-host networking over Thunderbolt-family ports on Unraid (TB3/4/5 and USB4-class hosts where Linux exposes them). One cable, one peer, eth-like settings (tbn0, tbn1, …), services on TB IPs, known peers, harden, activity — honest trained rate/lanes, not a promise of sticker 40 Gb/s dual-lane or dual-cable bonding.
