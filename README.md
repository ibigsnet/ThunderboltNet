**Thunderbolt Net**

Host-to-host networking over Thunderbolt 3/4/5 and USB4/USB4 v2 on Unraid. Per-link settings (`tbn0`, `tbn1`, …), fabric overview, trained rate and lanes, peers, and optional OpenFabric multi-host fabric when FRR is available via Fabric Routing (not required for static single-cable peers).
