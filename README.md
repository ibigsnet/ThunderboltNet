**Thunderbolt Net**

Host-to-host networking over Thunderbolt 3/4/5 and USB4/USB4 v2 on Unraid. Per-link `tbnN` tabs (static / DHCP client / DHCP server), Saved peers by fabric UUID, optional Share host uplink (NAT) for peers without their own WAN, bridging into existing `br0`, and optional OpenFabric when FRR is available via Fabric Routing.
