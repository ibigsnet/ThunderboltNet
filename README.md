**Thunderbolt Net**

Plug-and-play host-to-host networking over Thunderbolt-family ports on Unraid (Thunderbolt 3/4/5 and USB4-class hosts where Linux exposes them). Fabric overview, per-link settings (tbn0, tbn1, …), PCI/IOMMU, driver options, remembered peers, and activity hints—not locked to one generation.
