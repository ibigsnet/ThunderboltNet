# Releases and install channels

| Branch | Audience | Install URL |
|--------|----------|-------------|
| **`main`** | **CA / production** | `https://raw.githubusercontent.com/ibigsnet/ThunderboltNet/main/thunderboltnet.plg` |
| **`testing`** | Latest WIP — may be untested or broken | `https://raw.githubusercontent.com/ibigsnet/ThunderboltNet/testing/thunderboltnet.plg` |

Community Applications installs from **`main`**. Prefer **main** unless you intentionally want WIP.

Pinned tags (`vYYYY.MM.DDxx`) remain installable by raw URL when published.
